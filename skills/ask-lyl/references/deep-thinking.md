# 深度思考引擎

采用“固定底座＋问题结构路由＋覆盖检查”。深度来自找到会改变结论的结构，而不是堆叠模型、篇幅或内部推演。

## 固定底座

先确定：

1. 表面问题与真正需要作出的判断；
2. 目标、硬约束、时间范围和利益相关者；
3. 已核验事实、来源主张、用户解释、隐含假设、价值前提和未知；
4. 最可能改变问题定义、首选方案或风险等级的变量；
5. 应直接分析、搜索、询问用户，还是交给现实实验。

用户要求“直接告诉我”只规定答案形态，不构成支持某个选项的证据，也不自动创造截止时间。没有方向性证据时，判断应是暂不锁定选项，并给出对称验证或可逆试验。

## 按问题结构路由

只使用可能改变结论的工具。一个问题可组合多个工具，但必须服务同一分析主线。

| 问题结构 | 主要工具 |
|---|---|
| 多个选项中选择 | 双向钢人、决策透镜、多路径探索 |
| 检验已有观点 | 双向钢人、红队检验、证伪条件 |
| 寻找策略或方案 | 多路径探索、约束分析、现实试验 |
| 解释为何发生 | 因果拆解、替代假设、区分性证据 |
| 概念模糊或定义冲突 | 概念澄清、边界、操作性定义 |
| 真实冲突控制局面 | 矛盾映射、关键张力、转化条件 |
| 目标与行动不一致 | 现实校准、激励与约束分析 |
| 大量混乱输入 | 问题结构提取，再选择相关工具 |

## 澄清假设与因果

把决定性输入区分为：

- 事实：已有可靠依据；
- 来源主张：有人明确提出，但仍需判断真实性或适用性；
- 解释：对事实含义的理解，需要与替代解释比较；
- 假设：分析依赖但没有充分证据；
- 未知：尚未取得答案；
- 价值前提：决定“应该选择什么”的偏好与责任分配。

分析因果时：

1. 定义结果、时间、范围和分布；
2. 区分症状、直接原因、促成因素、硬约束和反馈回路；
3. 保留至少一个能解释同一现象的替代假设；
4. 寻找区分假设的证据，而不是只收集支持首个解释的材料；
5. 优先验证贡献最大的少数原因。

相关性、时间先后和权威判断都不能单独证明因果关系。

## 双向钢人

适用于用户已有倾向、存在真实正反立场、容易受确认偏误影响，或各方可能在回答不同问题时。

1. 重述双方都愿意承认的真正问题；
2. 分别构造支持与反对当前倾向的最强论证；
3. 删除依赖夸张、弱证据或误解对方的论点；
4. 判断分歧属于事实预测、价值排序、风险承受还是时间尺度；
5. 找出最可能使理性的人改变立场的变量；
6. 回到结论：维持、修改或撤回，并说明原因。

当双方最强理由、真实分歧和反转变量已经清楚时停止。不要为了对称制造弱论点。

自主思考模式中，先让用户尝试构造最强反方，再由人工智能补强并裁决；参谋模式由人工智能完成双方分析。

## 决策透镜

按需选择：

- 第一性原理：去除惯例后仍成立的事实与约束；
- 机会成本：选择会放弃的最好替代方案；
- 二阶影响：直接结果之后的反应与反馈；
- 长期复利：重复行为、路径依赖和能力轨迹；
- 激励分析：谁获益、谁承担成本、信息如何偏移；
- 概率判断：基准率、证据区间和明确的定性方向；
- 逆向思考：失败条件、止损线和不可逆禁区。

没有数据或可解释估算方法时，不生成百分比。

## 多路径探索

当当前选项可能是伪二分，保留两到四条真正不同的路径，包括可逆试验或分阶段方案。比较适用条件、收益、代价、可逆性和最早验证信号，淘汰违反硬约束的路径，推荐当前最合适的路径并说明切换条件。

不要通过给同一方案换名字制造多个选择。证据不足时，优先设计同任务、同期限、同验收标准的对称验证。

## 矛盾映射

只在真实冲突、相互依存和动态转化决定问题时使用。不要把普通约束或优缺点强行包装成矛盾。

输出问题结构：

- 表面问题：当前描述；
- 主要矛盾：控制其他问题的核心冲突及因果依据；
- 关键张力：两到四组真实张力；
- 隐藏矛盾：证据支持或明确标记为探索假设的遮蔽问题；
- 转化条件：优势、风险或关系发生转化的条件；
- 真正问题：一到三个真正值得解决的问题；
- 现实检查：下一步必须验证的事实。

不存在主要矛盾时，使用普通约束、因果或权衡分析。

## 覆盖与红队检查

形成初步判断后，在后台扫描：

- 是否遗漏会推翻问题定义的假设；
- 是否存在更强反方或第三条路径；
- 是否遗漏机会成本、二阶影响、激励、失败条件或不可逆风险；
- 是否把症状误认为原因；
- 是否把用户表达的目标当作已经由行动证明的真实优先级；
- 哪项新事实最可能推翻当前判断；
- 失败会以什么早期信号出现；
- 代价是否由没有参与决策的人承担。

只有遗漏会实质改变结论时才补充工具。不要输出工具打卡清单。

## 收束

自然呈现：真正问题、决定性分析、明确或条件化判断、最大代价或脆弱假设、反转条件、一个高杠杆下一步。用户需要选择时，不用“各有利弊”代替判断；证据不足时也不强行选边。
